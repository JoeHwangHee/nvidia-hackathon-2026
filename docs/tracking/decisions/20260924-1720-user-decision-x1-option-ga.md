# X1 NemoClaw 고지 수락과 재시도 사용자 결정

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-09-24(목) 17:20(기록 시각). 사용자의 답은 같은 날 17:10 무렵에 채팅으로 받았다 |
| 제목 | X1 (가)안: NemoClaw 제3자 소프트웨어 고지를 수락하고 다시 시도 |
| 결정 | X1(구현 첫날의 세로형 최소 통합 시험)에서 NemoClaw(OpenShell, 곧 에이전트를 격리해 돌리는 NVIDIA 샌드박스 런타임 위에서 에이전트를 돌리는 NVIDIA 참조 스택) 설치기가 요구한 제3자 소프트웨어 고지를 수락하고, NemoClaw 시연 경로를 다시 시도한다. 설치기의 표기는 "NemoClaw license and third-party software notice"다 `[미확인: 설치기 출력 원문은 남지 않았다. X1 PR로 병합할 artifacts/openshell/violation_tests.md에 X1 구현 에이전트가 옮겨 적은 표기만 있다]`. **수락한 쪽은 사용자다.** 모델 트랙(판정 정책·조사 흐름·NVIDIA 연동을 맡는 구현 흐름)의 구현 에이전트가 사용자의 선택에 따라, 사용자 대신 설치 명령을 고지 수락 옵션(`--yes-i-accept-third-party-software`)으로 실행했다(같은 날 17:17, NemoClaw v0.0.124) |
| 선택의 근거 | 오케스트레이터(작업을 나누고 PR(GitHub 변경 요청)을 병합하는 주관 에이전트)는 두 안을 제시했다. (가)는 "고지를 수락하고 NemoClaw를 시도한다(권장)", (나)는 "지금 바로 OpenShell만 쓰는 대체 경로로 간다"다. 오케스트레이터는 "(가)를 고르면 명령을 실행하는 것이 곧 고지 수락"이라고 알리고, 고지 요지를 함께 보였다. 요지는 세 가지다. NemoClaw 자체는 Apache 2.0 오픈소스다. 설치 중에 OpenClaw(NemoClaw의 기본 에이전트) 등 제3자 소프트웨어를 받아 온다. 그 소프트웨어는 각자의 약관을 따르고 있는 그대로(AS IS) 제공된다. 고지 전문은 보이지 않았다. 사용자는 "(가)안 다시 시도하고"라고 답했다 `[사실: 2026-09-24(목) 채팅]`. 요지의 출처는 X1 구현 에이전트의 16:07 보고이고, 설치기 고지 원문과 대조하지 않았다 `[미확인]`. 대회 조사 문서(`NVIDIA-FastCampus-Korea-Agentic-AI-Hackathon-2026.md`) 9절 3번은 NemoClaw 공식 고지에 "자율 에이전트 실행에는 시스템 접근·데이터 노출·보안 취약점 리스크 내재"라는 문구가 있다고 적는다. 이 위험 문구는 사용자에게 보인 요지에 없었다. 그래서 오케스트레이터가 X1 결과를 보고할 때 사용자에게 따로 알린다 |
