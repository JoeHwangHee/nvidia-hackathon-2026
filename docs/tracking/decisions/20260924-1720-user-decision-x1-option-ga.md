# X1 NemoClaw 고지 수락과 재시도 사용자 결정

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-09-24(목) 17:20(기록 시각). 사용자의 답은 같은 날 17:10 무렵에 채팅으로 받았다 |
| 제목 | X1 (가)안: NemoClaw 제3자 소프트웨어 고지를 수락하고 다시 시도 |
| 결정 | X1(구현 첫날의 세로형 최소 통합 시험)에서 NemoClaw(OpenShell, 곧 에이전트를 격리해 돌리는 NVIDIA 샌드박스 런타임 위에서 에이전트를 돌리는 NVIDIA 참조 스택) 설치기가 요구한 라이선스·제3자 소프트웨어 고지를 수락하고, NemoClaw 시연 경로를 다시 시도한다. 사용자는 이 안을 "(가)안 다시 시도"로 골랐다. 이 선택에 따라 모델 트랙 구현 에이전트가 설치 명령을 고지 수락 옵션(`--yes-i-accept-third-party-software`)으로 실행했다(2026-09-24(목) 17:17, NemoClaw v0.0.124). 수락 기록 파일 `~/.nemoclaw/usage-notice.json`이 생긴 것을 확인했다 `[사실: 17:22 파일 존재 확인]` |
| 시한과 시험 방식 | 오케스트레이터(작업을 나누고 PR(GitHub 변경 요청)을 병합하는 주관 에이전트)는 NemoClaw 시도의 벽시계 마감을 같은 날 19:30으로 정했다. 사용자를 기다린 시간은 X1의 3시간 시한에 넣지 않는다. 시험은 요건 (b)를 채우는 구성 하나만 한다. 요건 (b)는 외부 전송을 NVIDIA 추론 엔드포인트로만 허용하고 L7(HTTP 요청 수준) method·path를 명시하는 정책 요건이다. 구성은 세 가지다. 게이트웨이(샌드박스 밖에서 정책을 적용하고 요청을 중계하는 OpenShell 구성요소)의 추론 경로를 지워 `inference.local`(샌드박스가 보는 관리형 추론 주소)을 끈다. OpenClaw(NemoClaw의 기본 에이전트)를 헤더 치환 방식의 키 설정으로 `integrate.api.nvidia.com`에 직접 잇는다. 정책은 `openclaw` 실행 파일과 `POST /v1/chat/completions`만 연다. 이 구성으로 돌지 않으면 승인된 예외(`20260924-1504-user-approval-x1-exception.md`)대로 멈추고 사용자 결정을 받는다 |
| 이유와 근거 | NemoClaw 경로는 MVP(최소 기능 제품) 합격 체크리스트 1번과 자기채점 `1c`(NemoClaw 활용 깊이 지표)에 닿는다 `[사실: docs/plan/ROADMAP.md §3, docs/eval/RULEBOOK.md Part A]`. S0(앱 뼈대)가 외부 자문 회신을 기다리는 동안 병렬로 진행하므로 일정 부담이 작다. OpenShell만 쓰는 대체 경로는 X1 1차 시험에서 이미 확인됐다 `[추론]` |
| 검토한 대안 | (나) 바로 OpenShell만 쓰는 대체 경로로 간다: 측정된 실패 없이 승인된 순서(로컬 → Brev → OpenShell만)를 건너뛴다. Brev(NVIDIA 원클릭 클라우드 개발 환경)로 옮긴다: 고지 수락은 거기서도 필요하고, `inference.local` 동작은 OpenShell 판의 특성이라 두 문제를 풀지 못한다 `[추론]` |
| 결정 주체 | 사용자(선택), 오케스트레이터(마감 시각) |
