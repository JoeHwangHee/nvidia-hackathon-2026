# 사용자 결정: 봉인 원본 커밋 위치 `eval/sealed/`와 결과표 위치 `docs/eval/RESULTS.md`

로드맵 R1의 두 `[미확인]` 경로를 정했다. 둘 다 계획 경로·명령 표(자료 계약 `docs/rules/DATA_CONTRACT_V1.md` §10)에 새 행을 더하는 공용 약속 변경이다.

용어

- 봉인 원본: 저장소 밖 봉인 폴더에 두었던 파일 전부(holdout40 입력·정답표·생성 코드·부모 원본 계열 ID, real_sealed 사례 목록·채점 표본·표본 추출 seed). 최종 정답 대조 채점이 끝난 뒤 커밋한다(병렬 개발 규칙 §6.2, 룰북 B6).
- 결과표: 로드맵 R1의 결과 정리 문서(대표·보조 지표와 Wilson 95% 구간·등급, A등급 주장 조건 판정, B7 공개 값, 정직한 한계).
