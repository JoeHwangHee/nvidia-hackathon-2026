# 사용자 결정과 실행 기록: 저장소 공개 전환(로드맵 P2 실행)

로드맵 P2를 실행한 기록이다. 공개 저장소는 2026-09-26(토) 20:50 사용자 결정(결정 기록 `docs/tracking/decisions/20260926-2050-user-decision-public-repo-procedure-ops-plan.md`)으로 현재 저장소로 정해져 있었고, 이번 결정은 공개 전환을 누가 언제 하는지 정했다. 오케스트레이터가 그 지시대로 공개 전환을 했다.

용어

- 공개 전환: GitHub 저장소의 공개 범위(visibility)를 비공개(private)에서 공개(public)로 바꾸는 일. 되돌릴 수는 있지만, 공개된 동안 복제되거나 캐시된 사본은 남는다.
- E2E 시험(End-to-End): 실제 브라우저에서 사용자 흐름을 처음부터 끝까지 눌러 보는 시험. 여기서는 aside(사용자 PC의 브라우저 자동화 도구)의 `aside repl`로 했다.
- 미러 복제(`git clone --mirror`): 원격 저장소의 모든 참조(브랜치·태그·PR 참조)를 그대로 받아 오는 복제. 공개하면 드러나는 커밋 집합을 그대로 재현한다.

## 남은 것

- 라이선스: 사용자 결정 대기다. 오케스트레이터 권장은 Apache-2.0이다. 정해지면 LICENSE 파일을 더하고 거버넌스 카드 3개의 라이선스 칸을 채워 다시 렌더한다(스킬 사전 §3.5 ②, `docs/eval/SKILL_DICTIONARY.md`).
- 제출(사용자): 제출 폼 최종본 "제출 절차"의 1단계(교육 미션)와 8~10단계(팀장 제출 → 팀원 전원 제출 → 제출 뒤 키 재발급)가 남았다.
- 선택: 공개 저장소 기준 자기채점 추가 회차. 규범 G4의 "GitHub만 보고" 조건과 `4a`를 다시 확인하는 것이며, 사용자가 원할 때만 한다(자기채점 3회차 결과 파일 "계산" 절).
- 이 문서 PR이 병합되면 공개 저장소에 바로 드러난다. 뒤에 오는 모든 PR도 같다.
