# 사용자 결정: 제출 폼 최종본을 저장소 `docs/submission/`에 넣고, Tech Stack에 운영 전환·확장 계획 절을 더한다

로드맵 P3(제출 문서)의 산출물 표에 없던 제출 폼 입력용 최종본을 저장소에 둔다. 계획 경로·명령 표(자료 계약 `docs/rules/DATA_CONTRACT_V1.md` §10)에 새 행을 더하는 공용 약속 변경이다.

용어

- 제출 폼 최종본: 대회 신청 폼의 장문 칸 3개(Problem Definition·Solution·Tech Stack)에 붙여 넣는 평문과 서비스 파일(한 쪽) 내용을 담은 문서. 숫자는 결과표 `docs/eval/RESULTS.md`와 자기채점 3회차 파일에서 글자 그대로 옮긴다.
- 서비스 파일: GitHub 링크를 적어 올리는 pdf 또는 word 1개. 파일 이름은 대회 안내의 `[NVIDIA 해커톤_팀명_프로젝트명]` 규칙.
