# 사용자 결정: 담당자용 화면 3개(디자인 승인·영문판 추가)와 Codex 대체 검토 경로 승인

제출 시나리오 C(화면 1개)에 담당자용 화면을 더하는 결정과, Codex(OpenAI의 코딩 에이전트 CLI) 교차 검토를 받을 수 없을 때의 대체 경로 승인이다.

용어

- 담당자용 화면: 내부 구조를 모르는 무역통계 담당자(가상)가 쓰는 화면. 지금 화면 1 "사례 보기"는 조사 실행 기록을 보는 관리자용 화면으로 남긴다.
- 보조 화면: 담당자가 조사 결과에 응답하는 자리(결정 기록·재조사 요청·사후 확인·용어 도움).
- Codex 대체 경로: Codex 판정을 두 번 시도해도 받지 못하면 Claude 독립 검토자(읽기 전용, 같은 관점)의 판정으로 병합하고, Codex 재검토는 한도가 풀리면 받는다(`docs/rules/AGENT_OPS.md` §2.5의 "사용자가 승인할 수 있는 대체 경로").
