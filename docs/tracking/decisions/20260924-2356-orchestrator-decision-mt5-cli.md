out_dir=실행 폴더, stamp=시각, policy=정책 또는 없음)`이 실행 폴더에 파생 SQLite `snapshot_build-{시각}.sqlite`와 빌드 기록 `snapshot_build-{시각}.json`을 쓴다. 빌드 기록은 정본 옮기기(`install_build`)와 출처 대조가 읽는다. 반환이 빌드 기록이 아니거나 두 파일 가운데 하나라도 없으면 4다. 정책을 읽지 못하거나(이때 S2를 부르지 않는다) 빌드가 실패하면 1이다. 비교국 표 파일은 CLI가 넘기지 않는다. 그래서 CLI로 만든 빌드는 `peer_group` 표가 비어 있고, 로드맵 DT7 ②의 최종 빌드로 쓰지 않는다. 넘기는 수단은 `g1` 동결과 최종 빌드의 순서와 함께 정한다(`docs/tracking/findings.md`의 "`g1` 동결이 최종 스냅샷 빌드보다 늦다" 항목). `snapshot-verify`는 단위 S3 `run({"snapshot_id"})`의 JSON 보고를 `outputs/snapshot_verify-{시각}/snapshot_verify-{시각}.json`에 이미 있으면 실패하는 방식으로 쓴다. S3는 정본 빌드와 그 옆 빌드 기록을 대조한다. 검증 합격 여부는 보고의 불리언 `ok`로 본다(참이면 0, 거짓이면 1, 없거나 불리언이 아니면 4). 개발 빌드를 CLI로 검증하는 수단은 두지 않았다. 표준 출력에는 `outputs/`부터의 상대경로만 적는다 ⑦ CLI 실행 폴더의 부모는 현재 폴더 기준 `outputs/`다. 샌드박스 안 CLI의 출력 위치는 MT5 두 번째 PR이 정한다. 현재 폴더 기준 출력의 가드(현재 폴더가 봉인 폴더나 `data/snapshots/` 아래면 거부, `outputs`가 심볼릭 링크면 거부)도 그 PR에서 출력 위치 규칙과 함께 정한다. 그 전까지 CLI는 저장소 루트에서 부른다 ⑧ 오류 문장은 받은 값을 되풀이하지 않는다. CLI 자신의 문장에는 값을 넣지 않는다. argparse 문장은 모르는 인자의 옵션 이름 모양(ASCII `--` 뒤 영문 소문자·하이픈, 32자 이하)만 남기고, 선택지 밖 값·받지 않는 명시 값·그 밖의 값은 `<값 생략>`으로 바꾼다. 남은 경로 모양 조각은 `<경로 생략>`으로 가리고, 제어 문자(유니코드 Cc·Cf, 줄·문단 구분자)는 역슬래시 표기로 적는다. 출력 인코딩이 한국어를 못 써도 역슬래시 표기로 쓴다(자료 계약 §10.3 N13) |
