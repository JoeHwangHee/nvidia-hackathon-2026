# `real_dev` 결과로 조사 지침과 조사 흐름을 조정함

|---|---|

| 제목 | `real_dev`(실자료 개발 묶음)에서 본 실패를 반영해 조사 지침(모델 프롬프트)과 조사 흐름을 고칠지 |
| 배경 | ① `real_dev` MVP 사례 5건을 `full` 모드로 호스트에서 돌렸더니 `850432-PH-202302`·`850450-MY-202401`이 `INVALID`였다(나머지는 `COMPLETED` 1건, HTTP 429로 `FAILED` 2건). 막은 지적은 설명 문장·가설의 숫자·증감 어휘가 같은 보고서의 지표 주장으로 뒷받침되지 않음(`PROSE_UNBACKED`, 룰북 B3-2)과 발동한 신호의 지표 주장 누락(`SCHEMA_SIGNAL_CLAIM`)이었다. ② 오케스트레이터가 앱의 기록 재생(단위 I8)을 `run-case` 배선 그대로 돌려 두 실행의 모델 요청 13건을 다시 만들었다. 요청 해시(`request_sha256`) 13건이 모두 기록과 같았다. 같은 요청을 그대로, 또는 한 곳만 바꿔 NIM에 네 번씩 보내고(31회, 503 오류로 1회 빠짐) 응답을 앱 검증기로 판정했다. ③ 결과: 같은 요청을 그대로 보내도 PH 3번 중 2번, MY 4번 중 3번이 `INVALID`였다(모델 설정 temperature 1.0의 무작위 생성). PH는 첫 초안이 검증기를 통과했고 규칙 참고값과도 맞았다. 그런데 검수자(Critic)가 네 번 모두 수정을 요구하며, 점유율 신호만 발동한 사례에 하위품목 분해(`decompose_hs`)를 요청했다. 그 요구로 고친 초안이 `INVALID`가 됐다. 검수자 지침에 "분해는 단가 신호일 때만"을 넣어도 네 번 중 두 번은 요청했다. 수정 단계에서 지침만 `model-1.3`으로 바꾸면 효과가 작았다(앞 초안의 숫자를 그대로 옮김). 첫 초안에서 `model-1.3`은 단위 붙은 숫자를 없앴지만, 검증기 기준 깨끗한 초안 비율은 `model-1.2`와 같았다(각 네 번 중 한 번) ④ 룰북은 `real_dev`를 "탐지 임계값·최소 기준 조정과 산문 패턴 보강에만" 쓰게 했다. 지침·흐름 조정은 그 범위 밖이었다. `RB-1`(평가 룰북의 첫 동결 버전)은 아직 동결 전이다 |

| 답 | "1.3 + 흐름 수정 (권장)" |
| 결정 | ① 룰북·자료 계약·개발 플랜이 적은 `real_dev`의 용도에 "조사 지침(모델 프롬프트)·조사 흐름 조정"을 더한다. 사유는 이 기록이다. `RB-1` 동결 전에 한다 ② 모델 설정 `model-1.3`을 쓴다(설명 문장·가설·검수자 지적 문장에 숫자 표현 금지, 발동한 신호마다 그 계열의 지표 주장을 넣는 규칙을 초안 규칙 맨 앞으로. AS2 결정 기록 `20260925-0605-model-decision-as2-run-case.md` ㉓) ③ 조사 흐름 수정 두 가지. 모든 모델 모드에 같은 규칙으로 둔다. (가) 검수자의 재조회 요청 가운데, 그 사례에서 발동하지 않은 신호에만 쓰는 도구 요청은 코드가 버리고 실행 추적(trace)에 남긴다. 지금 도구 표에서는 단가 신호 전용인 `decompose_hs`가 해당한다. (나) 수정 단계를 연 원인이 검수자의 수정 요구뿐이고, 수정 전 초안이 수정 전 검사(스키마 검사, `freeform`이 아니면 검증기까지)를 통과했는데 고친 초안이 최종 검사에서 막히면, 수정 전 초안의 보고서를 최종 보고서로 둔다. 도구·모델 예산은 늘리지 않고, 버린 수정본은 실행 추적에 남긴다 ④ 병합 뒤 `real_dev` 사례 몇 건으로 확인하고 V1(MVP 시험)으로 간다 |
| 조건 | `real_sealed`·holdout40의 결과를 보지 않은 상태에서 정했다. 조정에 쓴 것은 `real_dev` 두 사례(`850432-PH-202302`, `850450-MY-202401`)의 실행 기록과 재생 실험뿐이다. `real_dev` 결과는 개발 값(등급 D)이며 대표 숫자로 올리지 않는다. 제출서와 결과 요약에 "`real_dev`에서 본 실패 유형으로 조사 지침과 흐름을 조정했다"를 밝힌다. 앞서 공개 문구로 정한 "모델 설정은 합성 A·B·C 3건으로 조정"(사용자 결정 13)은 이 조정을 더해 고쳐 적는다 |
