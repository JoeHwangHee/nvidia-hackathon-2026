# X1 NemoClaw 재시도의 마감과 시험 방식

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-09-24(목) 17:41(기록 시각). 결정은 같은 날 17:12 무렵 X1 재개를 지시할 때 했다 |
| 제목 | X1 NemoClaw 재시도의 마감과 시험 방식 |
| 결정 | ① 마감: X1(구현 첫날의 세로형 최소 통합 시험)의 NemoClaw(OpenShell 위에서 에이전트를 돌리는 NVIDIA 참조 스택) 재시도는 벽시계로 같은 날 19:30에 끝낸다. 19:15가 되면 새 시도를 멈추고 기록·커밋한다. ② 사용자를 기다린 시간(16:07~17:12)은 X1의 3시간 시한에 넣지 않는다. ③ 시험 방식: 요건 (b)를 채우는 구성 하나만 시험한다. 요건 (b)는 외부 전송을 NVIDIA 추론 엔드포인트로만 허용하고, L7(HTTP 요청 수준) method·path를 명시하며, `rules`(요청 허용 규칙) 생략과 범용 바이너리(`curl`·`python3`·`node`처럼 어떤 요청이든 보낼 수 있는 실행 파일) + `/**`(모든 경로) 조합을 쓰지 않는 정책 요건이다(`docs/plan/DEV_PLAN.md` §4.1). 구성은 세 가지다. 게이트웨이(샌드박스 밖에서 정책을 적용하고 요청을 중계하는 OpenShell 구성요소)의 추론 경로를 지워 `inference.local`(샌드박스가 보는 관리형 추론 주소)을 끈다. OpenClaw(NemoClaw의 기본 에이전트)를 credential placeholder rewrite로 `integrate.api.nvidia.com`에 직접 잇는다. 이 방식은 샌드박스에는 자리표시 문자열만 두고, 게이트웨이가 요청 헤더에 실제 키를 넣는다(개발 플랜 §4.6은 헤더에 넣는 동작을 `[미확인]`으로 적었고, X1 1차 시험이 확인했다). 정책은 `openclaw` 실행 파일과 `POST /v1/chat/completions`만 연다. ④ 17:45 무렵 보탠 판단: OpenClaw 2026.7.1의 `openclaw`는 node 스크립트라서 샌드박스는 실행 파일을 `node`로 판정한다 `[사실: X1 진행 기록]`. 요건 (b)가 금지하는 것은 범용 바이너리 + `/**` 조합과 `rules` 생략이다. 범용 바이너리라도 추론 요청 한 경로로 좁히는 것은 설계가 허용한다(개발 플랜 §4.1 작성 원칙). 그래서 추론 블록에 node를 넣고 경로를 `POST /v1/chat/completions` 하나로 좁히는 것은 요건 (b)에 맞는다고 보았다. 03 문서 §5의 하드닝 템플릿이 node를 빼라고 한 것과는 다르며, 그 차이를 X1 증거에 적는다. ⑤ 그래도 돌지 않거나, `/**`·`rules` 생략·다른 호스트 허용이 필요하면 승인된 예외(`20260924-1504-user-approval-x1-exception.md`)대로 멈추고 사용자 결정을 받는다. 키를 샌드박스에 넣는 우회는 하지 않는다(운용 규칙 §1.4 (b)). 에이전트에 요청을 보내기 전에 요건 (c)(샌드박스 안 키 비보유) 키 조회 시험을 먼저 돌린다 |
| 19:30에 닿으면 | 한 줄 경로가 통과하지 못했으면 로드맵 §7.1대로 한다. 원인이 두 예외(키 주입 두 방식 모두 실패, 요건 (b) 미충족)면 즉시 사용자 결정을 받는다. 그 밖이면 Brev(NVIDIA 원클릭 클라우드 개발 환경) 단계로 가야 한다. 다만 Brev 계정과 인스턴스는 사용자 몫이고 키를 클라우드 호스트에서 쓰게 되므로, 옮기기 전에 사용자에게 알린다. 19:30은 X1이 실제로 쓴 시간이 약 3시간(1차 48분 + 17:12부터 2시간 18분)에 닿는 시각과 거의 같다 |
| 이유와 근거 | ① 로드맵의 오늘 도착점과 내일 MVP(최소 기능 제품) 시험이 가깝다 `[사실: docs/plan/ROADMAP.md §1]`. ② 3시간 시한은 기술적 난도를 재려는 것이라, 사용자 결정을 기다린 시간을 넣지 않았다 `[DESIGN]`. 이 제외는 계획 문서에 없던 새 판단이다. 대체 경로(Brev → OpenShell만)를 여는 시점을 그만큼 늦춘다. 대체 경로가 발동하면 자기채점 `1c`(NemoClaw 활용 깊이 지표)가 0~1점, `1a`(NVIDIA 기술 개수 지표)가 구성요소 4개 이하로 묶이므로, 가능하면 NemoClaw 경로를 살리는 쪽으로 판단했다 `[추론: 룰북 A2 1c 주석, 부록 39번]`. ③ X1 1차 시험에서 `inference.local`이 샌드박스 정책 밖의 게이트웨이 라우터로 처리돼 어떤 실행 파일이든 쓸 수 있었다. 정책 블록으로 좁히면 요청이 멈췄다 `[사실: X1 1차 시험 기록, X1 PR로 병합 예정]`. 그래서 `inference.local`을 좁히는 반복 시도는 시간만 쓴다고 보았다 `[추론]` |
| 검토한 대안 | 마감 없이 3시간 시한만 쓰는 안: 사용자 대기가 끼면 밤까지 밀린다. `inference.local`을 좁혀 다시 시험하는 안: 위 ③의 이유로 버렸다 |
