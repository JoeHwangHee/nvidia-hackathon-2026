### 1-4. 판정: "HS 세번별"인가 "표준품명별"인가

**[사실·측정] 두 성격이 혼합된 구조다.** 최상위 조인 키는 `HS부호`(10단위) 컬럼이므로 **HS 세번 단위로 연결 가능**하다. 다만 한 HS부호에 여러 표준품명(품명번호)이 딸려 있고, 그중 일부만 다시 `규격번호`로 묶인 '필수규격×규격값' 하위 표(허용 코드 목록)를 갖는 구조다. 즉 데이터는 "세번 → 표준품명(들) → (있으면) 필수규격 코드표" 3단 트리이며, 관세청이 실제로 부여한 명칭도 "HSK 표준품명"이다.

### 1-5. V4 검증기 설계에 대한 리스크 [추론]

`필수규격_한글` 값 상위 빈도를 집계하면 `제조사`(8,640건), `연식`(7,680건), `실린더용량`(1,656건) 등 **87류(자동차)류 중고차·부품 신고용 코드가 압도적 다수**를 차지한다. 84/85/39/90류에서는 `용도`, `종류`, `변속기타입`류가 드문드문 나타날 뿐, 이 필드는 "류별 공통 필수 속성 스키마"가 아니라 **개별 HS부호(특히 특정 물품군)에 국한된 신고 규격 코드 열거표**에 가깝다. "류별 필수 속성 목록"을 이 컬럼에서 자동 생성하려면, 류 단위가 아니라 **HS부호(10단위) 단위로 그룹화한 뒤 커버리지(해당 류의 몇 %가 필수규격을 가지는지)를 반드시 확인**해야 한다. 예: 39류는 36행 중 필수규격 있는 행이 일부에 불과 → 류 전체를 대표하는 속성이 아님.

### 2-4. 세액 차이 계산 예시 [추론 — 가정 기반]

**가정**: 과세가격 1억원, 자동차용 플라스틱 범퍼를 3926.90(WTO협정세율 6.5%, 저세율)으로 신고했으나 실제로는 8708.10(범퍼 완제품, WTO협정세율 13%)에 해당한다고 관세청이 경정하는 경우.

```
세율 차이 = 13% - 6.5% = 6.5%p
추징(부족)관세액 = 100,000,000원 × 6.5% = 6,500,000원
```

※ 실제 적용세율은 기본세율(A)과 협정세율(C) 중 낮은 쪽이 원칙적으로 적용되며, 원산지·FTA 여부에 따라 달라질 수 있어 위 계산은 **두 코드의 WTO협정세율 차이만을 이용한 단순 예시**이며 실제 신고 사안의 적용세율 결정 로직(관세율 적용 순위, 관세법 제50조 등)까지 반영한 것은 아니다. [DESIGN 주의 필요]

## 5. 가산세 계산 규칙 + 예시

### 5-1. 관세법 제42조(가산세) 원문 핵심 [사실]

출처: https://www.law.go.kr/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900019695 (국가법령정보센터, 시행 2026.8.11. 법률 제21858호)

- 제1항: 미납부세액/부족세액 징수 시 가산세 = **1호(부족세액의 10%)** + **2호(가목: 이자상당액 + 나목: 3%)**
- 제2항: **부정한 행위**로 과소신고한 경우 = **부족세액의 60%** + 제1항제2호 금액 (2024.12.31 개정으로 기존 40%에서 60%로 상향된 것으로 확인, 조문 개정이력에 2024.12.31 표기)
- 제3항: 무신고(제16조제11호 물품) = **해당 관세액의 20%**(밀수·통고처분 대상인 경우 **60%**) + 이자상당액 등
- 제4항: 이자 계산기간은 최대 5년 한도
- 제5항: 체납관세 150만원 미만이면 이자상당액(2호가목) 미적용

### 5-2. 시행령상 이자율 [사실]

- 관세법 시행령 제39조(가산세): "대통령령으로 정하는 이자율"은 **1일 10만분의 22 (0.022%/일)** — 2022.2.15. 이후 적용 (이전 25/100,000, 그 이전 3/10,000) https://www.clhs.co.kr/lawlink.asp?strlaw=관세법시행령&strjo=제39조 [비공식·행정해석 사이트, 조문 원문은 law.go.kr에서 별도 재확인 권장 — 이번 조사에서 law.go.kr 시행령 원문 페이지는 열람했으나 제39조 세부 숫자는 검색결과 스니펫으로만 확인, 직접 재조회 필요] [미확인 일부]
- UNI-PASS 관세법령정보포털(CLIP) 공식 요약: "가산세 = 부족세액의 10%(부정신고 40%) + 납부지연가산세(부족세액×기간×이자율), 납부지연가산세율 : 일 10만분의 22 (2022.02.17.기준)" — **주의: CLIP 페이지의 "부정신고 40%"는 구법(2024.12.31 개정 전) 수치로 보이며, 위 5-1의 법 원문(60%)이 최신** [사실 vs 미확인 — 두 출처 간 시점 불일치, 최신 법령이 우선] https://unipass.customs.go.kr/clip/ctensrch/openULS0401007Q.do

### 5-3. 계산 예시 [DESIGN — 가정 기반, 계산식 명시]

**가정**: 과세가격 1억원, 정상세율 대비 세율 차이 8%p(저세율로 과소신고), 신고일로부터 2년(730일) 경과 후 경정·고지, 단순 과소신고(부정행위 아님, 10% 가산세율 적용)

```
① 부족세액 = 100,000,000원 × 8% = 8,000,000원
② 가산세(1호, 부족세액의 10%) = 8,000,000원 × 10% = 800,000원
③ 이자상당액(2호가목) = 8,000,000원 × 730일 × (22/100,000)
   = 8,000,000 × 0.00022 × 730
   = 1,285,600원
④ 가산세 합계(①의 부족세액 제외, 가산세만) = ② + ③ = 800,000 + 1,285,600 = 2,085,600원
⑤ 총 납부액(부족세액 + 가산세) = 8,000,000 + 2,085,600 = 10,085,600원
```

(부정행위로 인정될 경우 ②가 60%로 상향되어 800,000원 → 4,800,000원, 합계 6,085,600원 + 부족세액 = 14,085,600원)

## 6. 수입신고 흐름 (공식 소스)

**출처**: 관세청 "수입 통관" 안내 페이지, https://www.customs.go.kr/kcs/cm/cntnts/cntntsView.do?cntntsId=817&mi=2819 [사실]

### 6-1. 공식 단계 (원문 인용/요약)

1. **화주**: 수입신고 의뢰

3. **요건확인 신청** → 요건확인기관 검토/승인 (전산망 연계기관은 전자문서 신청 가능)

6. **수입신고수리**
7. **화물반출 승인통보** → 보세구역에서 **물품반출**

세금납부는 신고수리 후 이루어지며(신용등급 높은 업체는 사후납부 가능), 신고필증은 세관특수청인·워터마크·2차원 바코드 등 위변조 방지 장치를 포함한다(원문).

## 7. 미확인·리스크

- **표준품명 '필수규격'의 류별 커버리지**: 84/85/39/90류에서 필수규격이 채워진 행 비율이 낮고(예: 39류 36행 중 소수), 대다수(제조사/연식/실린더용량)는 87류(자동차) 편중 → "류별 필수 속성 목록 자동 생성"은 세번 단위 그룹화 + 커버리지 검증 없이는 신뢰하기 어려움.
- **관세율표 "전체 행: 1"** 포털 표기는 실제 파일(38만행)과 불일치 — 등록 오류로 추정되나 공식 확인 안 됨.
- **8517.62 vs 8471.80, 8543.70 vs 8479.89, 3907.29 vs 3824.99** 세 쌍은 상위 코드 수준에서 유의미한 기본세율 차이를 찾지 못함. 데모용으로는 **8708.10 vs 3926.90**(WTO협정세율 13% vs 6.5%) 조합이 가장 명확하나, 이마저도 실제 적용세율 결정(관세율 적용 순위, FTA 여부)까지 반영한 것은 아님.
- **가산세 시행령 이자율(22/100,000)**은 2차 출처(clhs.co.kr, UNI-PASS CLIP)에서 확인했고 law.go.kr 시행령 원문 제39조 조문 전체를 직접 열람해 재확인하지 못함 — 실제 반영 전 law.go.kr에서 재검증 필요.
- **가산세 부정행위 가산율 40%→60% 개정**은 law.go.kr 조문(2024.12.31 개정)과 UNI-PASS CLIP 페이지(40% 표기, 구버전 가능성) 간 불일치 확인 — 법조문이 최신이므로 60%를 채택했으나, 시행일자(경과규정) 확인은 못함.
- **오분류 사례의 "구체 금액"**은 조세심판원·법원 공식 결정문에서 전부 마스킹(OOO)되어 있어, 정확한 숫자는 언론 보도(taxwatch.co.kr) 인용에 의존 — 해당 언론사가 관세청/조세심판원으로부터 비마스킹 원문을 입수했는지 여부는 확인 불가. [보도] 태그로 신뢰도 구분 필요.
- **casenote.kr**은 비공식 미러 사이트([비공식] 태그) — 조세심판원 원문 사이트(tt.go.kr)에서 같은 결정문 직접 재확인은 이번 조사 시간 내 수행하지 못함.
- **UNI-PASS 수입신고서 필드명**("품목번호"/"란번호" 등)은 공식 화면으로 직접 확인하지 못함.
