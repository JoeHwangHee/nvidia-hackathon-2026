# R2b 제7부·제39류·제18부·제90류 주 규정

## 0. 원문 접근 URL과 형식 (기계판독 가능 여부)

**[사실]** CLIP(관세법령정보포털)의 "관세율표" 메뉴가 가장 확실한 접근 경로다.

- 진입 URL: `https://unipass.customs.go.kr/clip/index.do?opnurl=/hsinfosrch/openULS0201002Q.do` (관세율표-부류목록, UI-ULS-0201-002Q)
- 여기서 "한국 [2026년]" 등 연도별 탭이 있고, 부(部)/류(類) 링크를 순차 클릭하면 호목록(UI-ULS-0201-004Q) 페이지로 이동한다.
- 류(예: 제39류) 링크를 클릭하면 우측 패널(해설서 뷰어, `generic [scrollable]`)에 **"제39류 플라스틱과 그 제품 주:"**로 시작하는 조문 전체가 텍스트로 렌더링된다. 자료출처는 "2022년도 WCO 해설서"로 명시됨.
- 부(部) 레벨(예: 제7부)도 동일한 방식으로 "제 7 부 ... 주:" 텍스트가 뜬다. 단 **제18부처럼 법정 주(Note)가 없는 부는 "해설서 보기" 팝업(`openULS0202002Q.do`)을 열어도 류 제목만 나오고 주 조문 텍스트가 없다** [사실, 2026-09-23 확인].
- 형식: HTML (accessibility tree로 텍스트 추출 가능, 스크린샷 불필요). **기계 판독(복사/파싱) 가능** — 브라우저 접근성 트리에서 전체 조문이 plain text로 노출됨. 별도 로그인 불필요.
- law.go.kr 쪽은 "관세법 별표 1 관세율표"의 첨부파일(`flDownload.do?flSeq=...`) PDF로도 열람 가능하나, 검색으로 찾은 `flSeq=89091609` 파일은 **1997년 개정판**(제3901~3911 화학적 합성 범위·주2 제외목록 항목 수가 현재와 다름 — 예: 현재 주2는 "가~어"까지 세분화되어 있고 폴리글리콜 조제유압액(3819호) 제외 등이 추가돼 있으나 1997년판에는 반영 안 됨)이라 **현행 세율표 주와 다를 수 있어 근거자료로 부적합**. law.go.kr에서 최신 시행 별표를 직접 찾으려면 "관세법 별표1" 조문 페이지에서 최신 개정일자의 첨부파일을 다시 확인해야 함 [미확인 — 최신 flSeq 미특정].
- 결론: **CLIP 관세율표(unipass.customs.go.kr)를 1차 소스로 채택**. law.go.kr는 보조/교차검증용으로만 사용하되 첨부파일 버전(개정일자) 반드시 확인 필요.

## 3. 제18부 주 유무 + 제90류 주 (조항 표 + 주1 제외 표 + 주2 부분품 규칙)

### 3-1. 제18부 주 유무

**[사실]** 제18부(광학기기·사진용기기·영화용기기·측정기기·검사기기·정밀기기·의료용기기, 시계, 악기, 이들의 부분품과 부속품)는 **부(部) 차원의 법정 주(Note)가 없다.** CLIP에서 제18부 "해설서 보기" 팝업을 열어도 부 제목만 표시되고 조문 텍스트가 없음을 확인 (제7부·제16부 등과 대조적으로 텍스트 블록 부재) [사실, 2026-09-23 CLIP 확인]. 이는 HS 구조상 제18부에 속한 제90·91·92류가 각자 류 주(Chapter Notes)만 가지고 부 주는 두지 않는 일반적 패턴과 일치 [추론, WCO 노멘클레이처 일반구조 근거].

## 4. 결정 속성 (조문 근거)

### 제39류
- **형태(일차제품 vs 판/시트/필름 vs 성형품)**: 3901~3914호는 "일차제품"에만 적용(주6), 3920/3921호 "판·시트·필름·박·스트립"은 미절단 또는 정사각형/직사각형 절단품에 한정(주10) → 형태가 1차호/2차호를 가른다.
- **가공도(절단·표면가공)**: 주10 — 정사각형·직사각형 이상으로 절단하면 판/시트가 아닌 다른 호(가공품)로 이동.
- **화학적 합성 여부 및 범위 제한**: 주3 — 3901~3911호는 화학적 합성 제조품 중 4개 범주에만 적용(임의의 고분자물질이 아님).
- **공중합체 단량체 비율(95% 기준)**: 주4 — 단일단량체 95%미만이면 공중합체로서 최대중량 단량체 기준 호 결정.
- **화학적 변성 여부**: 주5 — 변성 중합체는 원 중합체 호 유지(그라프트공중합체 예외).
- **단면형상(관/파이프/호스 vs 형재)**: 주8 — 원형/타원형/직사각형(1.5배 이하)/정다각형 여부로 3917호(관)와 3916호(형재)를 가름.
- **용도(건축용 목록 한정)**: 주11 — 3925호는 열거된 건축용품 11항목에만 적용, 그 외는 3926호(잔여호) 또는 다른 호.
- **웨이스트/1차제품 여부**: 주7 — 단일 열가소성 웨이스트는 3915호 제외, 3901~3914호로 재분류.

### 제90류
- **다른 류(84·85·91) 우선원칙**: 주2 가목 — 특정 호 해당 시 해당 호 우선, 90류 잔여호(9033) 아님.
- **전용/주용도 원칙**: 주2 나목 — 특정 기기 전용 또는 주로 사용되는 부분품·부속품만 해당 기기와 함께 분류.
- **기능단위기계 개념(주기능 기준)**: 주3, 제16부 주3·4 준용 — 다기능/복합기계는 주기능으로 분류.
- **의료·수의료용 임플란트 특례**: 주1바목 단서 — 범용성 부분품이라도 임플란트 전용 설계는 9021호.
- **9013 vs 9031 경합 시 9031 우선**: 주5.
- **무기·잠수함용 조준경/잠망경 특례**: 주4 — 9005호 제외, 9013호로.
- **정형외과용 기기 정의(기능 기준)**: 주6 — 장애 예방·교정, 지지·고정 기능.
- **자동제어기기(9032) 여부 판단**: 주7 — 물리량 실시간 측정+피드백 제어 설계 여부.
- **재질 원칙적 불문, 단 예외적 재질 제외**: 주1가목 — 경화고무 외 가황고무/가죽·콤퍼지션레더/방직용섬유제품은 재질 기준으로 제외.

## 6. 미확인·리스크

- **law.go.kr 최신 관세율표 별표 PDF 정확 URL/flSeq 미특정** — 검색으로 찾은 첨부파일(`flSeq=89091609`)은 1997년 개정판으로 확인되어 현행 주 규정과 표현이 다름(예: 제39류 주2 제외항목 개수·순서 상이). 최신본을 얻으려면 law.go.kr에서 "관세법 별표1" 최신 시행일 개정 이력을 직접 열람해 정확한 flSeq를 찾아야 함. [미확인]
- **CLIP 텍스트의 "법적 효력" 여부** — CLIP 화면 자체가 "2022년도 WCO 해설서" 출처로 표기되어 있어, 국문 번역이 관세법 시행령(대통령령) 별표의 공식 조문과 완전히 동일한 조사(助詞)·번호 체계인지 문구 단위 대조는 하지 않았음. 실무 적용 시 관세법 시행령 별표 원문과 재대조 권장. [추론]
- **제39류 주2 "가"목 원문**: CLIP 표시상 "제2710호나 제3403호의 조제 윤활유"로 나왔는데, 통상 알려진 39류 주2가목은 "제2710호 또는 제3403호의 조제 윤활유"로 동일 내용이며 오기 아님 확인. 다만 병기된 "나"는 접속조사(또는)로 정상 표기. [사실]
- **HS 2022 제90류 개정호 3~5개 요건은 충족(3개)하나 4~5번째 후보(예: 9022 세부, 9013 레이저 관련 변경)는 WCO Table I에서 명시적 "Remarks" 문구를 찾지 못해 보류**. [미확인]
- **제18부 부주 부재는 CLIP 화면상 확인**이나, 법령(관세법 시행령 별표1) 원문에서 제18부 항목 자체에 "주" 제목이 아예 없는지(즉 별표상 "주" 헤더가 원천적으로 생략)까지는 1차 조문(law.go.kr 최신본)으로 교차검증하지 못함. [추론]
- 20분 내 조사 완료 목표에 따라 제91·92류(제18부 소속 다른 류)의 주는 조사 범위 밖(요청 항목 아님)으로 미수행.
